# SEPS 2.0 - Student Engineering Project System

Full-stack Student & Faculty Project Allocation and Management System for SRM Institute of Science and Technology.

## Architecture
- **Frontend**: React 19, Tailwind CSS, Vite, Lucide Icons
- **Backend**: Node.js Express, Prisma ORM
- **Database**: Cloud MySQL / TiDB Serverless
- **Deployment**: Hugging Face Spaces (Docker Container, Free Tier)
